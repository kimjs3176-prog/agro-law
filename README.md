# 🌾 KOAT Work Place

**한국농업기술진흥원(KOAT) 임직원을 위한 업무 지원 웹 서비스**입니다.
사내 규정(내규)과 국가법령을 한 화면에서 찾아 읽고, 기업·특허·지원사업 같은 공공데이터를 조회하고,
지출결의서·일정관리 같은 반복 업무를 처리할 수 있습니다.

> 브라우저만 있으면 됩니다. 설치나 회원가입 없이 PC와 휴대폰에서 모두 쓸 수 있습니다.

## 주요 기능

### 📋 내규똑똑 — 사내 규정 검색
- **키워드 검색**: 검색어가 들어간 조문을 규정별 카드로 모아 보여 줍니다. 카드 본문은 조문 위주로 보여 주고 부칙(시행일·개정 연혁)은 뺍니다.
- **의미 검색**: 단어가 달라도 뜻이 비슷한 조문을 함께 찾습니다. *(Gemini 키가 설정된 경우)*
- **자동완성**: 입력하는 동안 규정명을 제안합니다. 선택하면 전문이 바로 열립니다.
- **조문 바로 보기**: `여비규정 제5조`처럼 입력하면 해당 조문으로 바로 이동합니다.
- **관련 법령**: 내규가 참조하는 국가법령이 결과 옆에 함께 표시됩니다.
- **전문 열람**: 조문 목차, 검색어 하이라이트, 조문별 🔖 북마크와 📝 메모를 쓸 수 있고, 규정 간 참조를 클릭해 이동할 수 있습니다.
- **최근 개정 알림**: 최근에 개정된 내규가 있으면 검색창 근처에 알림 상자로 표시됩니다.

### 🏛 법령 조회 — 국가법령
- 법령명이나 키워드로 검색하면 **매칭 조문**을 법령별 카드로 보여 줍니다. 관련 사내 규정도 함께 표시됩니다.
- **자동완성**으로 법령명을 제안하고, 선택하면 원문이 바로 열립니다.
- 원문 위쪽에 **연계 법령 바**가 있어 [법률·시행령·시행규칙] 사이를 바로 오갈 수 있습니다. **현행·시행일** 배지로 지금 보고 있는 시행본도 확인할 수 있습니다.
- **준용조문 링크**
  - 「법령명」 제N조, "같은 법 제N조"를 누르면 해당 조문으로 이동합니다.
  - 시행령·시행규칙 본문의 "법 제N조", "영 제N조"는 모법과 시행령으로 연결됩니다.
  - 마우스를 올리면 미리보기가 나옵니다.
- 항상 법제처 **현행 법령**을 기준으로 불러옵니다.

### 🗂 열람 작업공간
- 전문을 열면 검색 목록 아래 **작업공간 창**에 문서가 열립니다. 여러 문서를 **나란히 비교**할 수 있습니다(내규와 법령을 섞어도 됩니다).
- 배치는 타일(가로·세로)과 자유 배치 중에서 고르고, 창을 최소화해 책갈피로 내려둘 수 있습니다.
- `⤢` 버튼을 누르면 전체화면 패널이 열립니다(AI 해석·조문 메모·비교).

### 🔎 공공데이터 조회
- **기업**: 회사명, 사업자번호, 대표자로 검색합니다. 국세청 사업자 상태(계속·휴업·폐업)와 과세 유형을 확인할 수 있습니다.
- **특허**
  - 출원인(고객번호·이름)이나 키워드로 검색합니다. 상태 필터, 검색어 하이라이트, IPC 태그, 존속기간·소멸임박 표시를 지원하고 엑셀로 내보낼 수 있습니다.
  - 특허 상세에서는 출원인·발명자를 구분해 보여 주고, **등록원부**(권리자·연차료 등)도 확인할 수 있습니다.
- **지원사업**
  - 정부 지원사업 공고를 2열 카드로 보여 줍니다. 마감 D-day, 접수중만 보기, 정렬(마감임박·적합도·최신)을 지원합니다.
  - 관심 공고는 ☆로 저장할 수 있고, 저장한 공고의 마감일은 일정관리나 `.ics`(캘린더 파일)로 보낼 수 있습니다.

### 📅 일정관리
- **오늘** 탭 한 화면에 마감 임박 공고, 진행 중 할 일, 다가오는 일정, 북마크한 조문, 최근 검색을 모아 보여 줍니다.
- **할 일**: 대기·진행·완료 3단계로 관리하고 진행률을 표시합니다.
- **일정**: 월간 캘린더 칸에 일정 제목이 바로 보입니다. `.ics`로 내보낼 수 있습니다.
- **연락처**와 **메모**: 메모는 포스트잇 보드에 자유롭게 배치하거나 목록으로 볼 수 있습니다.
- 백업(JSON 내보내기)과 복원을 지원합니다.

### 🧾 지출결의서
- 일반 결의서와 다건 결의서를 지원합니다. 다건 결의서는 거래처별로 지출과목과 지급방식을 따로 입력하고, 순번·거래처·거래내용·과목·금액 표를 만들어 줍니다.
- **사업자번호 조회**로 상호와 사업자 상태를 확인할 수 있습니다. 한 번 입력한 거래처는 기억해 자동완성으로 제안합니다.
- 금액에 천 단위 콤마가 자동으로 들어가고, 한글 금액(일금 ○○원정)으로 변환됩니다.
- 본문에 `관련 : ○○팀-000(날짜)호`(가.)와 `붙임 : ○○`(마지막 항목)을 자동으로 구성합니다.
- 결과는 **한글(.hwpx) 파일**로 저장하거나 복사할 수 있습니다.

### 편의 기능
- **Ctrl + K**: 메뉴, 규정, 메모, 연락처, 자주 쓰는 문구를 한 번에 찾는 명령 팔레트입니다.
- **즐겨찾기**: 내규·법령·조문·공고를 담아 두고 바로 다시 엽니다.
- **자주 쓰는 문구**: 지출결의서와 메모 입력칸에 넣어 쓰는 문구를 저장합니다.
- **다크 모드**와 모바일 화면을 지원합니다.

## 빠른 사용법

1. **무엇을 찾을지 고릅니다.** 검색창 위에서 **[📋 내규 | 🏛 법령 | ✦ AI 질문]** 중 하나를 선택합니다.
2. **입력합니다.** 입력하는 동안 규정명·법령명이 제안됩니다.
   - 제안을 누르면 → 전문이 바로 열립니다.
   - `규정명 제N조`를 입력하면 → 해당 조문으로 바로 이동합니다.
   - 그냥 **Enter**를 누르면 → 키워드가 들어간 조문을 모아 보여 줍니다.
3. **결과 카드의 조문을 누르면** 작업공간에서 전문이 열리고 그 조문 위치로 이동합니다.
4. 검색어를 둔 채로 **범위만 바꾸면** 같은 검색어로 바로 다시 찾습니다.

> 💡 키보드: ↑↓로 제안 사이를 이동하고, Enter로 선택하고, Esc로 닫습니다. `Ctrl + K`는 전체 명령 팔레트를 엽니다.

## 개인정보와 데이터 저장

- **일정관리(할 일·일정·연락처·메모), 즐겨찾기, 최근 검색, 조문 메모·북마크, 거래처 기억**은 모두 **사용 중인 브라우저(내 PC)에만** 저장됩니다. 서버로 보내지 않습니다.
- 브라우저 데이터를 지우거나 다른 PC를 쓰면 보이지 않습니다. 중요한 메모는 일정관리의 **⬇ 백업**으로 파일을 보관해 두세요.
- AI 설정에 입력한 API 키는 **탭을 닫으면 삭제**됩니다(sessionStorage). 요청할 때는 헤더로만 전달합니다.

## 관리자 안내

### 기술 구성
- **프론트엔드**: 단일 페이지 `index.html` (Vanilla JS + CSS, 빌드 과정 없음)
- **백엔드**: Flask `api_server.py` — `/api/*` 요청 처리(법제처·공공데이터 연동, 내규 검색, hwpx 생성)
- **배포**: Vercel (`api/index.py`가 Python 서버리스 진입점, 정적 파일은 `index.html`·`regulations/`·`assets/`)

### 로컬 실행
```bash
pip install -r requirements.txt
python run_local.py          # http://localhost:5100 (PORT 환경변수로 변경 가능)
```

### 배포
- `main` 브랜치에 병합하면 Vercel이 **자동으로 배포**합니다. PR마다 미리보기(Preview) 주소가 생성됩니다.
- 환경변수는 Vercel 프로젝트 설정 → Environment Variables에서 등록합니다. **API 키는 코드나 저장소에 넣지 마세요.**

### 내규 추가·개정
1. `/upload` 페이지에서 개정·신규 내규 문서를 업로드합니다(`REG_UPLOAD_TOKEN` 필요).
2. 변환된 원문은 `regulations/<규정명>/`에 저장되고, 목록은 `regulations_manifest.json`에 반영됩니다.
3. 의미 검색 색인을 다시 만들 때는 `scripts/build_embeddings.py`를 실행합니다(`GEMINI_API_KEY` 필요).

## 자주 묻는 질문

**Q. 메모나 즐겨찾기가 사라졌어요.**
브라우저에만 저장되므로 브라우저 데이터를 지우거나 다른 PC·브라우저를 쓰면 보이지 않습니다. 일정관리의 **⬆ 복원**으로 백업 파일을 불러오세요.

**Q. AI 질문(시나리오)이 동작하지 않아요.**
상단 **✦ AI 설정**에서 API 키를 등록해야 합니다.

**Q. 기업·특허·지원사업 조회에 '서비스키 필요'라고 나와요.**
관리자가 해당 환경변수(위 표 참고)를 설정해야 조회할 수 있습니다.

**Q. 법령 원문이 예전 내용 같아요.**
원문은 법제처 **현행 법령**을 기준으로 불러옵니다. 원문 위쪽의 **현행 · 시행일** 배지를 확인하세요. 계속 다르면 법령명을 알려 주세요.

**Q. 개정된 내규가 반영되지 않았어요.**
관리자가 `/upload`에서 개정본을 올려야 반영됩니다. 반영된 뒤에는 검색창 근처의 **최근 개정 알림**에 표시됩니다.
